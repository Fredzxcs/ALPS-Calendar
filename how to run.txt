* General Application Run *

create .env file            // setup local env
copy .env.example to .env   // copy env.example setup 
composer install            // Install backend PHP dependencies
npm install                 // Install frontend JavaScript dependencies
npm run build               // Compile and build frontend assets
create db 'alpstraining'    // Create the database in MySQL
php artisan key:generate    // Generate the application encryption key
php artisan migrate         // Run the database migrations
php artisan serve           // Serve the application locally

php artisan config:clear
php artisan cache:clear


* UI Demo Mode (No Login, No DB) *

1) In .env, set these values:
APP_DEMO=true
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync

2) Install dependencies (one-time):
composer install
npm install

3) Build frontend assets:
npm run build

4) Run app locally:
php artisan key:generate
php artisan serve

5) Open in browser:
http://127.0.0.1:8000/calendar

Notes:
- Demo mode bypasses login on key calendar/access flows.
- Demo mode serves mock JSON from public/mock/ and does not require MySQL.
